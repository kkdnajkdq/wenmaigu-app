文脉估——非遗数据资产AI估值与融资辅助平台
用AI把非遗数据变成银行看得懂的信用资产。

项目简介
“文脉估”是一个面向非遗传承人与文化企业的数据资产估值平台。用户加载已采集的非遗项目数据后，系统通过六个智能体依次执行：数据加载、数据清洗、文化价值评估、经济价值评估、估值融合、报告生成，最终输出估值区间和一份可提交给银行的估值报告。

功能特性
数据加载：从CSV读取已采集的200条非遗项目数据

数据清洗：自动检测异常值，输出结构化输入

文化价值评估：基于CVI五维度模型计算文化价值指数

经济价值评估：测算播放量、销售额、IP授权次数的归一化得分

估值融合：套用国标公式 V = Vb × (1 + α × CVI)，输出估值区间

报告生成：自动生成含分类编码与登记要素的估值报告
